# AutoBackup

[English](README.md) | **العربية**

AutoBackup يراقب بهدوء المجلد الذي تعمل فيه ويحفظ نسخًا احتياطية مؤرخة عند حفظ ملف. إذا قام Photoshop أو Word أو برنامج آخر بالكتابة فوق نفس الملف مرارًا وتكرارًا، تظل النسخ الأخيرة محفوظة في مجلد منفصل.

2. اختر الملف المناسب لنظامك (Windows `.exe`، Linux binary أو macOS `.zip`).
3. شغّله. لا حاجة للتثبيت.

## المتطلبات

- Windows 10+ أو Linux (سطح مكتب) أو macOS
- **مجلد العمل** (مشاريعك)
- **مجلد النسخ الاحتياطي** في مكان مختلف - ليس داخل مجلد العمل (مثل قرص خارجي أو `D:\Backups`)

---

## بداية سريعة

1. افتح AutoBackup.
2. انقر **تصفح...** بجانب **مجلد العمل** واختر مجلد مشاريعك.
3. انقر **تصفح...** بجانب **مجلد النسخ الاحتياطي** واختر الوجهة.
4. انقر **بدء** واترك النافذة مفتوحة.
5. لرؤية نسخك، انقر **فتح النسخ الاحتياطية**.

السطر تحت الأزرار يخبرك بما يحدث: متوقف، مراقبة، أو نسخ ملف.

**ألوان الزر**

| اللون | المعنى |
|-------|--------|
| رمادي | متوقف |
| أخضر | مراقبة - النسخ الاحتياطي تلقائي |
| برتقالي | جاري نسخ ملف الآن |

## ماذا يحدث عند الحفظ

- عندما تضغط **بدء**، يسجل AutoBackup الملفات الموجودة بالفعل. **فقط الملفات التي تغيرها بعد ذلك** يتم نسخها احتياطيًا - ليس كل مجلدك دفعة واحدة.
- بعد الانتهاء من حفظ ملف، ينتظر AutoBackup لحظة ثم يحفظ نسخة بالتاريخ والوقت في الاسم، مثال: `MyDrawing_20260526_143022.psd`
- المجلدات الفرعية داخل مجلد العمل تُنسخ بنفس الطريقة داخل مجلد النسخ الاحتياطي.
- إذا حفظت نفس الملف مرة أخرى بدون تغييرات حقيقية، يتخطى AutoBackup إنشاء نسخة أخرى.
- الملفات المؤقتة، وذاكرة التخزين المؤقت (`.git`، `node_modules`، `__pycache__`) وملفات النظام (Thumbs.db، إلخ) تُستبعد تلقائيًا.
- حدد عدد النسخ المراد الاحتفاظ بها لكل ملف باستخدام عداد **الاحتفاظ بالنسخ** (1–100).

## إيقاف مؤقت واستئناف

- انقر **إيقاف مؤقت** لإيقاف المراقبة مؤقتًا - تبقى قائمة الملفات في الذاكرة، لا حاجة لإعادة الفحص عند الاستئناف.
- انقر **استئناف** لمتابعة المراقبة فورًا.
- استخدم الإيقاف المؤقت عندما تقوم بحفظ مجموعة من الملفات لا تريد نسخها احتياطيًا بعد.

---

## استعادة نسخة قديمة

AutoBackup لا يغير ملفات العمل الخاصة بك أبدًا من تلقاء نفسه.

- انقر **استعادة...** لتصفح جميع نسخك الاحتياطية مع البحث والتواريخ وأحجام الملفات.
- اختر ملفًا وانقر **استعادة إلى...** لحفظه مرة أخرى في مجلد العمل (أو أي مكان تختاره).
- أو انقر **فتح** لمعاينة نسخة احتياطية بدون استعادتها.

## معلومات مفيدة

- أبقِ AutoBackup قيد التشغيل أثناء العمل - إغلاقه يوقف الحماية.
- يجب **ألا** يكون مجلد النسخ الاحتياطي داخل مجلد العمل.
- يكتشف التطبيق تلقائيًا لغة Windows (العربية، العبرية، الروسية) أو يمكنك التبديل في أي وقت من قائمة اللغات (أسفل اليمين).
- حدد **بدء مع Windows** لتشغيل AutoBackup تلقائيًا عند تسجيل الدخول.
- حدد **صوت** لسماع صوت رقيق عند اكتمال النسخ الاحتياطي (متوقف افتراضيًا).
- يظهر حجم مجلد النسخ الاحتياطي بجانب عداد النسخ.
- هذه أداة مساعدة لملفات مشاريعك. لا تغني عن النسخ الاحتياطي الكامل للكمبيوتر أو التخزين السحابي أو برامج النسخ الاحتياطي الاحترافية.
