# AutoBackup

[English](README.md) | **עברית**

AutoBackup עוקב בשקט אחרי התיקיה שבה אתה עובד ושומר עותקי גיבוי עם תאריך כאשר אתה שומר קובץ. אם Photoshop, Word או תוכנה אחרת כותבים שוב ושוב על אותו קובץ, הגרסאות האחרונות נשמרות בתיקיה נפרדת.

## דרישות

- Windows 10+‎, Linux (שולחן עבודה) או macOS
- **תיקיית עבודה** (הפרויקטים שלך)
- **תיקיית גיבוי** במיקום אחר - לא בתוך תיקיית העבודה (לדוגמה כונן חיצוני או `D:\Backups`)

## התחלה מהירה

1. פתח את AutoBackup.
2. לחץ **עיון...** ליד **תיקיית עבודה** ובחר את התיקיה שלך.
3. לחץ **עיון...** ליד **תיקיית גיבוי** ובחר את היעד.
4. לחץ **התחל** והשאר את החלון פתוח.
5. כדי לראות את העותקים שלך, לחץ **פתח גיבויים**.

השורה מתחת לכפתורים אומרת לך מה קורה: עצור, צופה או מעתיק קובץ.

**צבעי כפתור**

| צבע | משמעות |
|------|--------|
| אפור | עצור |
| ירוק | צופה - גיבויים אוטומטיים |
| כתום | מעתיק קובץ כרגע |

## מה קורה כששומרים

- כאשר אתה לוחץ **התחל**, AutoBackup רושם אילו קבצים כבר קיימים. **רק קבצים שתשנה לאחר מכן** מגובים - לא כל הספרייה שלך בבת אחת.
- לאחר שסיימת לשמור קובץ, AutoBackup ממתין רגע ואז שומר עותק עם תאריך ושעה בשם, לדוגמה: `MyDrawing_20260526_143022.psd`
- תיקיות משנה בתוך תיקיית העבודה מועתקות באותו אופן בתוך תיקיית הגיבוי.
- אם תשים את אותו קובץ שוב ללא שינויים ממשיים, AutoBackup ידלג על יצירת עותק נוסף.
- קבצים זמניים, מטמונים (`.git`‎, `node_modules`‎, `__pycache__`‎) וקבצי מערכת (Thumbs.db וכו') לא נכללים אוטומטית.
- הגדר כמה עותקים לשמור לכל קובץ באמצעות בורר **שמור עותקים** (1–100).

## השהיה וחידוש

- לחץ **השהה** כדי להפסיק זמנית את המעקב - רשימת הקבצים נשמרת בזיכרון, אין צורך בסריקה מחדש בעת חידוש.
- לחץ **חדש** כדי להמשיך מיד.
- השתמש בהשהיה כאשר אתה עושה שמירות מרובות שאתה לא רוצה לגבות עדיין.

---

## שחזור גרסה ישנה

AutoBackup לעולם לא משנה את קבצי העבודה שלך בעצמו.

- לחץ **שחזר...** כדי לעיין בכל גרסאות הגיבוי עם חיפוש, תאריכים וגדלי קבצים.
- בחר קובץ ולחץ **שחזר אל...** כדי לשמור אותו בחזרה לתיקיית העבודה (או לכל מקום שתבחר).
- או לחץ **פתח** כדי לצפות בגיבוי מבלי לשחזר אותו.

## כדאי לדעת

- השאר את AutoBackup פועל בזמן העבודה - סגירה מפסיקה את ההגנה.
- תיקיית הגיבוי **חייבת** להיות מחוץ לתיקיית העבודה.
- האפליקציה מזהה אוטומטית את שפת Windows (ערבית, עברית, רוסית) או שאתה יכול להחליף בכל זמן מתפריט השפות (למטה מימין).
- סמן **הפעל עם Windows** כדי ש-AutoBackup יופעל אוטומטית בכניסה.
- סמן **צליל** כדי לשמוע צליל עדין כאשר גיבוי מסתיים (כבוי כברירת מחדל).
- גודל תיקיית הגיבוי מוצג ליד בורר העותקים.
- זה כלי עזר לקבצי הפרויקט שלך. הוא לא מחליף גיבוי מלא של המחשב, אחסון בענן או תוכנות גיבוי מקצועיות.
