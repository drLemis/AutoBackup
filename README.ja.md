# AutoBackup

[English](README.md) | **日本語**

AutoBackup は作業中のフォルダを静かに監視し、ファイルを保存すると日付入りのバックアップコピーを保存します。Photoshop、Word、その他のプログラムが同じファイルを何度も上書きしても、最新のバージョンは別のフォルダに保持されます。

## 必要なもの

- Windows 10+、Linux（デスクトップ）、macOS
- **作業フォルダ**（プロジェクト）
- 作業フォルダ**外**の**バックアップフォルダ**（例：外付けドライブや `D:\Backups`）

---

## クイックスタート

1. AutoBackup を開く。
2. **作業フォルダ**の横にある**参照...**をクリックしてフォルダを選択。
3. **バックアップフォルダ**の横にある**参照...**をクリックして保存先を選択。
4. **開始**をクリックし、ウィンドウを開いたまま作業。
5. コピーを確認するには**バックアップを開く**をクリック。

ボタンの下の行に現在の状態が表示されます：停止中、監視中、ファイルコピー中。

**ボタンの色**

| 色 | 意味 |
|-----|------|
| グレー | 停止中 |
| 緑 | 監視中 - 自動バックアップ |
| オレンジ | ファイルをコピー中 |

## 保存時の動作

- **開始**を押すと、AutoBackup は既存のファイルを記録します。**その後変更したファイルのみ**がバックアップされます - フォルダ全体が一度にバックアップされることはありません。
- ファイルの保存が完了すると、AutoBackup は少し待ってから日時を含む名前でコピーを保存します。例：`MyDrawing_20260526_143022.psd`
- 作業フォルダ内のサブフォルダは、バックアップフォルダ内でも同じ構成でコピーされます。
- 実際の変更なしで同じファイルを再度保存した場合、AutoBackup はコピーを作成しません。
- 一時ファイル、キャッシュ（`.git`、`node_modules`、`__pycache__`）、OS のゴミファイル（Thumbs.db など）は自動的に除外されます。
- **保持するコピー数**スピナー（1～100）で、ファイルごとに保持するコピー数を設定できます。

---

## 一時停止と再開

- **一時停止**をクリックすると監視を一時的に停止 - ファイルリストはメモリに保持され、再開時に再スキャンは不要です。
- **再開**をクリックすると即座に監視を再開。
- まだバックアップしたくないファイルをまとめて保存するときに一時停止を使用します。

---

## 古いバージョンの復元

AutoBackup は作業ファイルを自動的に変更することはありません。

- **復元...**をクリックすると、検索、日付、ファイルサイズ付きですべてのバックアップバージョンを参照できます。
- ファイルを選択し**復元先...**をクリックして、作業フォルダ（または任意の場所）に保存します。
- **開く**をクリックすると、復元せずにバックアップをプレビューできます。

## 知っておくと便利

- 作業中は AutoBackup を起動したままにしてください - 閉じると保護が停止します。
- バックアップフォルダは作業フォルダの**外**に置く必要があります。
- Windows の表示言語を自動検出（アラビア語、ヘブライ語、ロシア語）するか、言語メニュー（右下）からいつでも切り替えられます。
- **Windows と共に起動**にチェックを入れると、ログイン時に AutoBackup が自動起動します。
- **サウンド**にチェックを入れると、バックアップ完了時に音が鳴ります（デフォルトはオフ）。
- バックアップフォルダのサイズはコピー数スピナーの横に表示されます。
- これはプロジェクトファイルのための補助ツールです。PC の完全バックアップ、クラウドストレージ、専門的なバックアップソフトの代わりにはなりません。
