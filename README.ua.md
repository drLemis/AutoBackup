# AutoBackup

[English](README.md) | **Українська**

AutoBackup непомітно стежить за папкою, у якій ви працюєте, та зберігає резервні копії з датою в імені, коли ви зберігаєте файл. Якщо Photoshop, Word або інша програма знову й знову перезаписує той самий файл, останні версії залишаються в окремій папці.

## Що потрібно

- Windows 10+, Linux (робочий стіл) або macOS
- **Робоча папка** (ваші проєкти)
- **Папка для копій** в іншому місці - не всередині робочої папки (наприклад, зовнішній диск або `D:\Backups`)

---

## Швидкий старт

1. Відкрийте AutoBackup.
2. Натисніть **Огляд...** біля **Робоча папка** та виберіть вашу папку.
3. Натисніть **Огляд...** біля **Папка резервних копій** та виберіть призначення.
4. Натисніть **СТАРТ** і залиште вікно відкритим.
5. Щоб переглянути копії, натисніть **Відкрити копії**.

Рядок під кнопками показує, що відбувається: зупинено, спостереження або копіювання файлу.

**Кольори кнопки**

| Колір | Значення |
|-------|----------|
| Сірий | Зупинено |
| Зелений | Спостереження - копії створюються автоматично |
| Помаранчевий | Зараз копіюється файл |

## Що відбувається при збереженні

- Коли ви натискаєте **СТАРТ**, AutoBackup запам'ятовує, які файли вже є. **Копіюються лише файли, які ви зміните після цього** - не вся папка цілком одразу.
- Після збереження файлу AutoBackup трохи зачекає і збереже копію з датою та часом в імені, наприклад: `MyDrawing_20260526_143022.psd`
- Вкладені папки в робочій папці повторюються так само в папці копій.
- Якщо ви знову зберегли файл без реальних змін, AutoBackup не створить зайву копію.
- Тимчасові файли, кеші (`.git`, `node_modules`, `__pycache__`) та системне сміття (Thumbs.db тощо) автоматично виключаються.
- Налаштуйте кількість копій на файл за допомогою лічильника **Зберігати копій** (1–100).

---

## Пауза та продовження

- Натисніть **ПАУЗА**, щоб тимчасово зупинити спостереження - список файлів залишається в пам'яті, повторне сканування не потрібне.
- Натисніть **ПРОДОВЖИТИ**, щоб миттєво відновити спостереження.
- Використовуйте паузу, коли робите багато збережень, які ще не хочете копіювати.

---

## Як повернути стару версію

AutoBackup ніколи не змінює ваші робочі файли сам по собі.

- Натисніть **Відновити...**, щоб переглянути всі версії резервних копій з пошуком, датами та розмірами файлів.
- Виберіть файл і натисніть **Відновити в...**, щоб зберегти його назад у робочу папку (або в будь-яке інше місце).
- Або натисніть **Відкрити**, щоб переглянути копію без відновлення.

---

## Корисно знати

- Залишайте AutoBackup запущеним під час роботи - закриття зупиняє захист.
- Папка для копій **не повинна** знаходитися всередині робочої папки.
- Програма автоматично визначає мову Windows (арабська, іврит, російська) або ви можете перемкнути її вручну в меню мов (справа внизу).
- Позначте **Запускати з Windows**, щоб AutoBackup запускався автоматично при вході.
- Позначте **Звук**, щоб чути сигнал при завершенні копіювання (вимкнено за замовчуванням).
- Розмір папки копій відображається поруч із лічильником копій.
- Це помічник для файлів проєктів. Він не замінює повне резервне копіювання комп'ютера, хмару або професійні програми бекапу.
