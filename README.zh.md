# AutoBackup

[English](README.md) | **中文**

AutoBackup 静静监视您工作的文件夹，并在您保存文件时保存带有日期标记的备份副本。如果 Photoshop、Word 或其他程序反复覆盖同一个文件，最近的几个版本仍会保留在单独的文件夹中。

## 系统要求

- Windows 10+、Linux（桌面）或 macOS
- **工作文件夹**（您的项目）
- **备份文件夹**在不同位置 - 不要在工作文件夹内（例如外部硬盘或 `D:\Backups`）

---

## 快速开始

1. 打开 AutoBackup。
2. 点击**工作文件夹**旁边的**浏览...**并选择您的文件夹。
3. 点击**备份文件夹**旁边的**浏览...**并选择目标位置。
4. 点击**开始**并保持窗口打开。
5. 要查看备份副本，点击**打开备份**。

按钮下方的状态栏显示当前状态：已停止、正在监视、正在复制。

**按钮颜色**

| 颜色 | 含义 |
|------|------|
| 灰色 | 已停止 |
| 绿色 | 监视中 - 自动备份 |
| 橙色 | 正在复制文件 |

## 保存时发生什么

- 当您点击**开始**，AutoBackup 会记录已存在的文件。**只有之后修改的文件**才会被备份 - 不会一次性备份整个文件夹。
- 保存文件后，AutoBackup 等待片刻，然后保存带有日期和时间的副本，例如：`MyDrawing_20260526_143022.psd`
- 工作文件夹内的子文件夹会在备份文件夹中以相同方式复制。
- 如果您再次保存同一文件但没有实际更改，AutoBackup 会跳过创建副本。
- 临时文件、缓存（`.git`、`node_modules`、`__pycache__`）和系统文件（Thumbs.db 等）会自动排除。
- 使用**保留副本**计数器（1–100）设置每个文件保留的副本数量。

## 暂停和恢复

- 点击**暂停**以暂时停止监视 - 文件列表保留在内存中，恢复时无需重新扫描。
- 点击**继续**以立即恢复监视。
- 当您要批量保存文件但还不想备份时，请使用暂停。

---

## 恢复旧版本

AutoBackup 不会自行更改您的工作文件。

- 点击**恢复...**浏览所有备份版本，支持搜索、日期和文件大小。
- 选择文件并点击**恢复到...**将其保存回您的工作文件夹（或任何您选择的位置）。
- 或点击**打开**预览备份而不恢复。

## 实用信息

- 工作时保持 AutoBackup 运行 - 关闭程序会停止保护。
- 备份文件夹**不能**位于工作文件夹内。
- 应用会自动检测 Windows 显示语言（阿拉伯语、希伯来语、俄语），或您随时从语言菜单（右下角）切换。
- 勾选**随 Windows 启动**以在登录时自动启动 AutoBackup。
- 勾选**声音**以在备份完成时听到提示音（默认关闭）。
- 备份文件夹大小显示在副本计数器旁边。
- 这是一个项目文件辅助工具。它不能替代完整的电脑备份、云存储或专业备份软件。
