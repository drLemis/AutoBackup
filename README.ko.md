# AutoBackup

[English](README.md) | **한국어**

AutoBackup은 작업 중인 폴더를 조용히 감시하며 파일을 저장할 때 날짜가 포함된 백업 복사본을 저장합니다. Photoshop, Word 또는 다른 프로그램이 동일한 파일을 계속 덮어써도 최근 버전들은 별도의 폴더에 보관됩니다.

**[여기서 다운로드!](https://github.com/drLemis/AutoBackup/releases/latest)**

1. 위의 링크(또는 녹색 버튼)를 클릭하세요.
2. 시스템에 맞는 파일을 선택하세요(Windows `.exe`, Linux binary, macOS `.zip`).
3. 실행하세요. 설치가 필요 없습니다.

## 필요 사항

- Windows 10+, Linux(데스크톱) 또는 macOS
- **작업 폴더**(프로젝트 폴더)
- 작업 폴더 **외부**의 **백업 폴더**(예: 외장 드라이브 또는 `D:\Backups`)

---

## 빠른 시작

1. AutoBackup을 엽니다.
2. **작업 폴더** 옆의 **찾아보기...**를 클릭하여 폴더를 선택합니다.
3. **백업 폴더** 옆의 **찾아보기...**를 클릭하여 대상을 선택합니다.
4. **시작**을 클릭하고 창을 열어 둡니다.
5. 복사본을 보려면 **백업 열기**를 클릭합니다.

버튼 아래 줄에 현재 상태가 표시됩니다: 중지됨, 감시 중, 파일 복사 중.

**버튼 색상**

| 색상 | 의미 |
|-----|------|
| 회색 | 중지됨 |
| 초록색 | 감시 중 - 자동 백업 |
| 주황색 | 파일 복사 중 |

## 저장 시 동작

- **시작**을 누르면 AutoBackup이 이미 존재하는 파일을 기록합니다. **이후에 변경한 파일만** 백업됩니다 - 전체 폴더가 한 번에 백업되지 않습니다.
- 파일 저장이 완료되면 AutoBackup이 잠시 기다린 후 이름에 날짜와 시간이 포함된 복사본을 저장합니다. 예: `MyDrawing_20260526_143022.psd`
- 작업 폴더 내의 하위 폴더는 백업 폴더 내에서 동일한 구조로 복사됩니다.
- 실제 변경 없이 동일한 파일을 다시 저장하면 AutoBackup은 복사본을 만들지 않습니다.
- 임시 파일, 캐시(`.git`, `node_modules`, `__pycache__`), OS 정크 파일(Thumbs.db 등)은 자동으로 제외됩니다.
- **보관할 복사본** 스피너(1~100)로 파일당 보관할 복사본 수를 설정하세요.

## 일시 중지 및 재개

- **일시 중지**를 클릭하면 감시가 일시적으로 중지됩니다 - 파일 목록은 메모리에 유지되며 재개 시 다시 스캔할 필요가 없습니다.
- **재개**를 클릭하면 즉시 감시가 다시 시작됩니다.
- 아직 백업하고 싶지 않은 파일을 여러 개 저장할 때 일시 중지를 사용하세요.

---

## 이전 버전 복원

AutoBackup은 작업 파일을 자동으로 변경하지 않습니다.

- **복원...**을 클릭하면 검색, 날짜, 파일 크기와 함께 모든 백업 버전을 탐색할 수 있습니다.
- 파일을 선택하고 **다음으로 복원...**을 클릭하여 작업 폴더(또는 원하는 위치)에 저장합니다.
- 또는 **열기**를 클릭하여 복원하지 않고 백업을 미리 볼 수 있습니다.

## 알아두면 좋은 점

- 작업하는 동안 AutoBackup을 실행 상태로 두세요 - 종료하면 보호가 중지됩니다.
- 백업 폴더는 작업 폴더 **밖**에 있어야 합니다.
- Windows 표시 언어를 자동 감지(아랍어, 히브리어, 러시아어)하거나 언어 메뉴(오른쪽 아래)에서 언제든지 전환할 수 있습니다.
- **Windows와 함께 시작**을 체크하면 로그인 시 AutoBackup이 자동으로 실행됩니다.
- **소리**를 체크하면 백업 완료 시 소리가 납니다(기본적으로 꺼져 있음).
- 백업 폴더 크기가 복사본 스피너 옆에 표시됩니다.
- 이것은 프로젝트 파일을 위한 보조 도구입니다. 전체 PC 백업, 클라우드 스토리지 또는 전문 백업 소프트웨어를 대체하지 않습니다.
